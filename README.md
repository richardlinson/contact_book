# Contact Book

A command-line contact manager written in Python. Add, view, search, update, and delete contacts, then save them locally as JSON.

## Requirements

- Python 3.8 or later

No third-party packages are required.

## Run

From this directory, run:

```powershell
python .\contact_book_project.py
```

Choose an option from the menu. Select **6. Save & Exit** to write the contact list to `contacts.json` in the current working directory.

## Privacy

Contact details are personal data. The local `contacts.json` file is excluded from Git so saved contacts are not uploaded with the source code.
